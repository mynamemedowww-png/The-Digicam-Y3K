# The Digital Y2K — GitHub Pages

Website demo bán máy ảnh và phụ kiện cho bài tập thương mại điện tử.

## Có gì trong bản V3?
- Tên shop chính thức: **The Digital Y2K**.
- 6 sản phẩm máy ảnh dùng **ảnh chụp sản phẩm thật**, không còn hình máy ảnh CSS/illustration.
- 5 phụ kiện cross-sell.
- Giỏ hàng dùng LocalStorage.
- Checkout + QR VietQR mô phỏng.
- Responsive cho desktop/mobile.
- Chạy được trên GitHub Pages vì chỉ dùng HTML/CSS/JS.

## Lưu ý
Giá, tên model C01–C06 và thông tin tài khoản QR là dữ liệu mô phỏng cho bài tập. Nếu dùng thanh toán thật, thay thông tin ngân hàng trong `script.js`.

## Đưa lên GitHub Pages
1. Giải nén ZIP.
2. Mở thư mục `LumiCamV2`.
3. Upload `index.html`, `style.css`, `script.js` lên repository.
4. Vào **Settings → Pages**.
5. Chọn branch `main` và thư mục `/root`.
6. Save và mở đường dẫn GitHub Pages.
